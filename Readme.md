# Определение возраста покупателей по фотографии

## 📌 Описание проекта

Сетевой супермаркет **«Хлеб-Соль»** внедряет систему компьютерного зрения для обработки фотографий покупателей. Фотофиксация в прикассовой зоне поможет определять возраст клиентов, чтобы:

- **анализировать покупки** и предлагать товары, которые могут заинтересовать покупателей этой возрастной группы;
- **контролировать добросовестность кассиров** при продаже алкоголя.

**Проблема:** ручное определение возраста покупателя кассиром субъективно и может приводить к ошибкам при продаже алкоголя. Автоматизация процесса повысит точность и скорость обслуживания.

**Решение:** построена нейронная сеть на основе **ResNet50** (transfer learning) для определения приблизительного возраста человека по фотографии.

---

## 🎯 Цель исследования

Построить модель, которая по фотографии определяет приблизительный возраст человека. Метрика качества — **MAE** (Mean Absolute Error), целевое значение — **менее 8 лет** на валидационной выборке.

## 🔬 Ход исследования

### Шаг 1. Исследовательский анализ данных

**Загрузка данных:**
- Загружен `labels.csv` и изображения через `ImageDataGenerator`.
- Изображения приведены к размеру **224×224** пикселя, батч = 32.

**Проверка качества данных:**
- Дубликаты: **0**
- Пустые строки: **0**
- Все значения `real_age` — целочисленные (`int`).

**Распределение возраста:**
- Возраст варьируется от **0 до 100 лет**.
- Медианное значение — около **30 лет**.
- Большинство людей — в возрасте **15–45 лет** и **0–10 лет**.
- Основная масса — до 70 лет.

**Визуальный анализ фотографий (16 примеров):**
- Фотографии сильно различаются по:
  - **качеству** и детализации;
  - **цветовой палитре** (чёрно-белые и цветные);
  - **формату съёмки** (угол, кадрирование);
  - **направлению взгляда** (в камеру / в сторону);
  - **эмоциям и мимике**;
  - **наличию посторонних предметов**.

**Выводы для обучения модели:**
- Большой размах возрастов (до 100 лет) усложняет задачу.
- Разнообразие фотографий требует **аугментации данных** (горизонтальное/вертикальное отражение).
- Дисбаланс возрастов (больше молодых людей) может привести к смещению прогнозов.

### Шаг 2. Подготовка данных

**Аугментация:**
- `ImageDataGenerator` с `rescale=1./255`, `validation_split=0.25`, `vertical_flip=True`, `horizontal_flip=True`.
- Разделение на train (75%) и validation (25%).

**Train:** 5694 изображения (178 шагов по 32).
**Validation:** 1897 изображений (60 шагов по 32).

### Шаг 3. Обучение модели

**Архитектура:**
- **Backbone:** `ResNet50` (предобученные веса `imagenet`, `include_top=False`).
- **GlobalAveragePooling2D** — для уменьшения размерности.
- **Dense(1, activation='relu')** — выходной слой для регрессии (возраст — положительное число).

**Компиляция:**
- Optimizer: `Adam(lr=0.0001)`
- Loss: `mean_squared_error` (MSE)
- Metrics: `mae`

**Обучение:**
- 10 эпох, batch_size=32.
- Время обучения: ~43–74 секунды на эпоху.

**Динамика обучения:**

| Эпоха | Train Loss | Train MAE | Val Loss | Val MAE |
|---|---|---|---|---|
| 1 | 282.56 | 12.19 | 872.23 | 24.67 |
| 2 | 106.04 | 7.75 | 764.01 | 22.62 |
| 3 | 82.47 | 6.80 | 333.86 | 13.70 |
| 4 | 66.72 | 6.23 | 128.04 | 8.42 |
| 5 | 54.43 | 5.62 | 96.49 | 7.41 |
| 6 | 45.58 | 5.08 | 80.01 | 6.69 |
| 7 | 38.71 | 4.77 | 86.97 | 7.10 |
| 8 | 33.69 | 4.44 | 76.46 | 6.58 |
| 9 | 31.02 | 4.23 | 89.29 | 7.28 |
| 10 | 26.55 | 3.93 | 78.45 | **6.53** |

**Итоговая метрика MAE на валидации:** **~6.53** ✅ (критерий < 8 выполнен).

### Шаг 4. Анализ обученной модели

**Архитектура модели:**

| Layer | Output Shape | Param # |
|---|---|---|
| resnet50 | (None, 7, 7, 2048) | 23,587,712 |
| global_average_pooling2d | (None, 2048) | 0 |
| dense | (None, 1) | 2,049 |
| **Total params** | | **23,589,761** |
| Trainable params | | 23,536,641 |
| Non-trainable params | | 53,120 |

**Наблюдения:**
- Модель **немного переобучается** на тренировочных данных (train MAE ~3.93 против val MAE ~6.53).
- Причина — большое количество параметров ResNet50 для данной задачи.
- Несмотря на переобучение, **предсказательная способность на валидации улучшается** с каждой эпохой.
- Для улучшения метрики можно:
  - увеличить количество эпох;
  - увеличить размер батча;
  - добавить регуляризацию (Dropout, L2);
  - заморозить часть слоёв ResNet50.

## 📊 Результаты

| Метрика | Значение |
|---|---|
| **MAE на валидации** | **~6.53** ✅ |
| Критерий успеха | < 8 |
| Время обучения (10 эпох) | ~7–8 минут |

**Лучшая модель:** ResNet50 + GlobalAveragePooling2D + Dense(1, relu).

**Преимущества:**
- Использование предобученных весов ImageNet ускоряет сходимость.
- Аугментация данных повышает устойчивость модели.
- MAE ~6.5 лет — приемлемая точность для бизнес-задачи.

**Недостатки:**
- Переобучение из-за большого числа параметров.
- Дисбаланс возрастов в данных.

## 💡 Выводы для бизнеса

1. **Модель ResNet50** рекомендуется для внедрения в систему компьютерного зрения супермаркета:
   - MAE ~6.5 лет — достаточная точность для определения возрастной группы покупателя;
   - модель можно использовать для контроля продажи алкоголя и персонализации предложений.

2. **Ключевые особенности решения:**
   - transfer learning с ResNet50 существенно ускоряет обучение;
   - аугментация данных (отражение) повышает устойчивость к разным условиям съёмки;
   - MSE как функция потерь работает быстрее, чем MAE, при этом MAE используется как метрика.

3. **Рекомендации:**
   - дообучить модель на большем количестве эпох (15–20) для улучшения метрики;
   - добавить Dropout или L2-регуляризацию для борьбы с переобучением;
   - заморозить часть слоёв ResNet50 для ускорения обучения;
   - собрать более сбалансированный датасет по возрастам.
